ASRAR PASHA PORTFOLIO — SETUP

1. Extract this ZIP.
2. Extract your original “ASRAR PORTFOLIO VIDEOS.zip” into the asrar-pasha-portfolio folder. It should create: asrar-pasha-portfolio/Asrar PP/
3. Rename that extracted folder from “Asrar PP” to “media/Asrar PP” (create a folder named media first), OR update the HTML paths accordingly.
4. The portfolio uses the 11 selected clips and excludes duplicate DK-01 Final.mp4 and Kf 01.mp4.
5. Keep index.html, assets, and media together. Open index.html to preview.

Note: Some source videos use HEVC/AV1 codecs. Playback depends on browser/device codec support.
